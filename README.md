# 🛍️ Local PriceLister

A web application where shop owners can list their products and prices, helping customers compare prices and choose where to shop. Designed to promote local businesses and increase transparency in pricing.

---

## 🔑 Key Features

- User authentication for shop owners
- Add/edit/delete products with real-time pricing
- Public product listing page for all users
- Shop visit incentive based on listed prices
- Simple and intuitive user interface

---

## 🚀 Tech Stack

- **Frontend**: Next.js
- **Backend**: Nest.js
- **Database**: PostgreSQL
- **Authentication**: JWT
